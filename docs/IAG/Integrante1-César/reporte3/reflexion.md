# Reflexión

El uso de ChatGPT permitió comprender mejor la separación entre frontend y backend, así como identificar por qué el servidor Spring Boot mostraba un error 404 al acceder a una ruta sin configurar. También aprendí a utilizar Live Server para visualizar las interfaces durante el desarrollo y conocí una forma de integrar posteriormente los archivos del frontend dentro de Spring Boot.

Además, las consultas ayudaron a organizar las funcionalidades de ChordLab y definir las responsabilidades del equipo, especialmente en el desarrollo del reproductor musical. Esto permitió tener más claridad sobre las interfaces pendientes y su relación con los requerimientos del proyecto.
