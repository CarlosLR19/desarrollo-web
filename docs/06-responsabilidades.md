# 06. Responsabilidades del equipo – ChordLab

## 1. César Rodrigo Díaz Hernández– Análisis y desarrollo frontend

**Responsabilidad principal:** Diseño y desarrollo de la interfaz de usuario.

Actividades asignadas:
- Definir los requerimientos funcionales y no funcionales del sistema.
- Elaborar la descripción, problemática, justificación y objetivos del proyecto.
- Diseñar las interfaces de usuario.
- Desarrollar la página principal y el panel de proyectos.
- Implementar los formularios de registro e inicio de sesión desde el frontend.
- Desarrollar la interfaz del generador de acordes y progresiones.
- Implementar la navegación entre los diferentes módulos.
- Consumir los servicios del backend mediante Fetch API.
- Adaptar la interfaz a diferentes dispositivos y tamaños de pantalla.

## 2. Nino Alessandro Navarro Lam – Backend y lógica musical

**Responsabilidad principal:** Desarrollo de la lógica del servidor y las funcionalidades musicales.

Actividades asignadas:
- Configurar y desarrollar el backend utilizando Java y Spring Boot.
- Implementar los controladores y servicios de la API REST.
- Desarrollar el registro y autenticación de usuarios.
- Implementar las operaciones para administrar proyectos musicales.
- Desarrollar los algoritmos para generar acordes a partir de notas fundamentales y tipos de acordes.
- Implementar la generación de progresiones armónicas mediante reglas de teoría musical.
- Desarrollar las operaciones para modificar y organizar progresiones.
- Validar la información recibida desde el frontend.
- Documentar los endpoints y las respuestas de la API.

## 3. Carlos Vicente López Rosales – Base de datos e integración

**Responsabilidad principal:** Diseño, administración e integración de la base de datos y los componentes musicales.

Actividades asignadas:
- Diseñar el modelo entidad-relación de ChordLab.
- Definir las tablas, atributos, claves primarias y relaciones.
- Configurar la base de datos MySQL.
- Implementar las entidades y relaciones mediante JPA e Hibernate.
- Desarrollar las operaciones de persistencia y consulta de información.
- Implementar el almacenamiento de proyectos, secciones y progresiones musicales.
- Integrar el reproductor musical utilizando Tone.js y Web Audio API.
- Apoyar la integración entre frontend, backend y base de datos.
- Realizar pruebas de funcionamiento y persistencia de información.

## 4. Responsabilidades compartidas

Los tres integrantes participarán en las siguientes actividades:

- Revisar y validar los requerimientos del proyecto.
- Mantener actualizado el repositorio de GitHub.
- Realizar commits individuales que identifiquen los cambios realizados.
- Participar en las pruebas e integración de los módulos.
- Documentar los avances y problemas encontrados.
- Revisar el código desarrollado por los demás integrantes.
- Preparar la demostración y presentación final del proyecto.
- Conocer la arquitectura y el funcionamiento general del sistema para la defensa técnica individual.

## 5. Organización del trabajo

El desarrollo se organizará mediante la asignación de tareas según las responsabilidades de cada integrante. Cada uno deberá documentar sus avances y mantener comunicación con el equipo para facilitar la integración de los diferentes módulos.

La distribución de responsabilidades podrá ajustarse durante el desarrollo cuando sea necesario, procurando mantener una participación equilibrada y verificable de todos los integrantes.
