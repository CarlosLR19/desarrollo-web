# 07. Uso de inteligencia artificial – ChordLab

## 1. Introducción

Durante el desarrollo de ChordLab se permitirá utilizar herramientas de inteligencia artificial generativa como apoyo para realizar actividades de análisis, documentación, programación y resolución de problemas técnicos.

Su utilización tendrá como propósito facilitar el proceso de desarrollo y apoyar a los integrantes en la comprensión de diferentes conceptos y tecnologías relacionadas con el proyecto.

Los integrantes serán responsables de revisar, comprender y validar la información y el código obtenido mediante estas herramientas antes de incorporarlos al proyecto.

## 2. Herramientas utilizadas

Las herramientas de inteligencia artificial que se utilizarán durante el desarrollo son:

- **ChatGPT:** apoyo en la elaboración de documentación, explicación de conceptos técnicos, diseño de estructuras de software, generación de código y resolución de errores.
- **Claude (Anthropic):** apoyo en el análisis de documentación, revisión de código, razonamiento sobre problemas técnicos, generación de soluciones y asistencia durante el desarrollo del sistema. Se contempla el uso del plan Claude Pro.
- **GitHub Copilot:** asistencia durante la escritura, revisión y modificación de código, cuando esté disponible para los integrantes.

La utilización de estas herramientas podrá variar según las necesidades de cada actividad y las preferencias de los integrantes.

## 3. Áreas de aplicación

La inteligencia artificial podrá utilizarse en diferentes etapas del proyecto.

### 3.1 Documentación y análisis

Se utilizará como apoyo para:

- Elaborar y revisar los requerimientos funcionales y no funcionales.
- Organizar la documentación técnica.
- Comprender conceptos relacionados con arquitectura de software y API REST.
- Revisar el modelo entidad-relación.
- Analizar posibles mejoras en la organización del proyecto.

### 3.2 Desarrollo de software

Durante la programación podrá utilizarse para:

- Comprender estructuras y componentes de Java y Spring Boot.
- Generar ejemplos de código para el frontend y backend.
- Resolver errores de programación.
- Revisar consultas SQL y operaciones de persistencia.
- Apoyar la implementación de algoritmos para la generación de acordes y progresiones musicales.
- Elaborar y revisar pruebas de funcionamiento.

### 3.3 Resolución de problemas técnicos

También podrá utilizarse para interpretar mensajes de error, comprender problemas de configuración y proponer soluciones relacionadas con WSL, MySQL, Spring Boot y la comunicación entre los diferentes módulos.

## 4. Registro del uso de inteligencia artificial

Para mantener un registro del trabajo realizado, cada integrante documentará individualmente sus interacciones con herramientas de inteligencia artificial.

Se utilizarán dos tipos de registros:

**Registro de documentación (r-ia-doc.md)**

Se utilizará para registrar consultas relacionadas con explicaciones, análisis, documentación y resolución de dudas técnicas que no impliquen generación o modificación de código.

Cada registro deberá incluir:

- Fecha de consulta.
- Herramienta utilizada.
- Modelo utilizado, cuando esté disponible.
- Prompt original.
- Respuesta obtenida.
- Forma en que se utilizó la información.

**Registro de desarrollo (r-ia-dev-sxx.md)**

Se utilizará cuando la inteligencia artificial participe en la generación o modificación de código.

Cada registro deberá incluir:

- Herramienta y modelo utilizado.
- Prompt original.
- Respuesta obtenida.
- Identificación del commit anterior y posterior.
- Código antes y después de la modificación.
- Diferencias entre versiones.
- Pruebas realizadas.
- Reflexión sobre el resultado y los cambios efectuados.

## 5. Responsabilidad de los integrantes

Los tres integrantes serán responsables de registrar individualmente el uso que hagan de herramientas de inteligencia artificial durante el desarrollo.

- **Nino Alessandro Navarro Lam:** documentará las consultas relacionadas con el backend, la API REST y la lógica musical.
- **Carlos Vicente López Rosales:** documentará las consultas relacionadas con la base de datos, persistencia e integración.
- **César Rodrigo Díaz Hernández:** documentará las consultas relacionadas con el análisis, diseño de interfaces y desarrollo frontend.

Cada integrante deberá revisar y comprender las soluciones obtenidas, además de comprobar que los resultados sean compatibles con los requerimientos del proyecto.

## 6. Organización de los registros

Los registros individuales se almacenarán dentro de la carpeta `IAG`, ubicada en el directorio de documentación del repositorio.

Cada integrante contará con su propio directorio para organizar las consultas y evidencias correspondientes a las diferentes sesiones de trabajo.

También se incluirá una declaración firmada por los integrantes sobre el uso de inteligencia artificial durante el desarrollo del proyecto.

## 7. Criterios de utilización

El uso de inteligencia artificial se realizará bajo los siguientes criterios:

- Las respuestas obtenidas deberán revisarse antes de utilizarse.
- El código generado deberá comprenderse y probarse antes de incorporarse al proyecto.
- Se registrarán las consultas relevantes y las modificaciones realizadas con asistencia de IA.
- No se presentará contenido generado automáticamente como trabajo verificado sin haberlo revisado.
- Cada integrante será responsable de las contribuciones que realice al repositorio.
- Se mantendrá evidencia del proceso de utilización de estas herramientas.

## 8. Conclusión

La inteligencia artificial se utilizará como herramienta de apoyo durante las diferentes etapas de ChordLab. Su participación será documentada por cada integrante, permitiendo identificar las consultas realizadas, las modificaciones efectuadas y la manera en que se incorporaron los resultados al proyecto.
